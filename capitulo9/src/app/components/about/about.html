Acerca de esta aplicación

Esta aplicación fue desarrollada como una práctica para aprender el funcionamiento de Angular Router.

Objetivo

Comprender cómo Angular permite navegar entre diferentes componentes sin recargar completamente la página.

Temas utilizados

  • Configuración de rutas
  • Uso de RouterLink
  • Uso de RouterOutlet
  • Navegación entre componentes
  • Manejo de rutas no encontradas
Tecnología: Angular 21
