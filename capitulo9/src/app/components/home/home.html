Angular Router

Aplicación de práctica para aprender navegación entre componentes utilizando Angular Router.

Utiliza el menú de navegación para recorrer las diferentes secciones de la aplicación.

Navegación

Aprende a cambiar entre diferentes componentes sin recargar completamente la aplicación.

Rutas

Define las direcciones disponibles de la aplicación y relaciona cada ruta con un componente.

Componentes

Cada sección de la aplicación puede mostrarse mediante un componente diferente.
